# 🩺 Salud Landing — Landing Page Pediátrica & Embudo de Conversión

Sitio web web _Mobile-First_ y herramienta de captación de pacientes desarrollada para consulta pediátrica privada en Zapopan, Jalisco.

El proyecto combina un diseño moderno, rápido y accesible con una estructura basada en un **Embudo de Ventas (Sales Funnel)** para transformar visitas en citas agendadas vía WhatsApp.

🚀 **Demo en vivo:** [https://noemivaldiviagdl.github.io/salud-landing/](https://noemivaldiviagdl.github.io/salud-landing/)

---

## 🎯 Arquitectura del Embudo de Ventas

La estructura de la página sigue el recorrido psicológico del paciente (_User Journey_):

1. **TOFU (Top of Funnel) — Hero:** Captura de atención con propuesta de valor clara (_sin esperas, atención cálida_), gatillos de confianza e indicadores de disponibilidad.
2. **MOFU (Middle of Funnel) — About & Services:** Presentación de la especialista, acreditaciones (Cédulas profesionales), instalaciones del consultorio y servicios orientados a soluciones.
3. **BOFU (Bottom of Funnel) — Testimonials & FAQ:** Prueba social mediante Google Reviews y sección de preguntas frecuentes para destruir objeciones finales (costos, estacionamiento, urgencias).
4. **Conversión Inmediata — WhatsApp 1-Click:** Botón flotante y llamadas a la acción (_CTAs_) personalizadas en cada servicio para un contacto directo y sin fricción.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** React 18
- **Tooling / Bundler:** Vite
- **Estilos:** CSS3 nativo (Metodología BEM / Mobile-First)
- **Iconografía:** Lucide React
- **Widget de Reseñas:** Elfsight (Google Reviews integración dinámica)
- **Despliegue:** GitHub Pages (`gh-pages`)
